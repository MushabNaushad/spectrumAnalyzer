# Formatting Rule: No LaTeX

Never use LaTeX syntax (such as `$...$`, `$$...$$`, `\frac{...}{...}`, `\approx`, `\mu`, etc.) in responses.
Render all math, equations, formulas, variables, and units using plain text, standard ASCII, or readable markdown tables.
- Use `tau = R * C` instead of `\tau = RC`
- Use `Av = 1 + Rf/Rg` instead of `A_v = 1 + \frac{R_f}{R_g}`
- Use `uF`, `nF`, `pF`, `kohm`, `Megohm`, `us`, `ms` for units.
- Use `sqrt(...)` instead of `\sqrt{...}`
